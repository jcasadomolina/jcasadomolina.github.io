# Portfolio Web Project

Este proyecto es un portafolio personal que muestra información sobre mí, mis proyectos y habilidades. A continuación se detallan los archivos y su propósito:

## Estructura del Proyecto

```
portfolio-web
├── data.json          # Contiene datos personales, proyectos y habilidades.
├── src
│   ├── index.html     # Página principal del portafolio.
│   ├── css
│   │   └── styles.css # Estilos CSS para el portafolio.
│   └── js
│       └── app.js     # Lógica JavaScript para manejar interacciones y cargar datos.
├── package.json       # Configuración de npm y dependencias.
└── README.md          # Documentación del proyecto.
```

## Instalación

1. Clona este repositorio en tu máquina local.
2. Navega al directorio del proyecto.
3. Ejecuta `npm install` para instalar las dependencias necesarias.

## Uso

Para iniciar el proyecto, puedes abrir el archivo `src/index.html` en tu navegador. También puedes configurar un servidor local para una mejor experiencia de desarrollo.
